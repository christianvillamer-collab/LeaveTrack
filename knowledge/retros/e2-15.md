# E2-15 retro — Route-level HTTP authorization and envelope tests

## What landed

- Four committed, mock-based suites (`tests/route-auth-matrix.test.ts`, `tests/leave-route.test.ts`,
  `tests/jobs-route.test.ts`, `tests/health-route.test.ts`) cover all 15 `app/api/**/route.ts` files
  and all 18 exported verbs. The 19 matrix cases split GET `/api/leave-requests` into `mine` and
  `scope=team`.
- The matrix uses the real `lib/auth/policy.ts` and real Zod schemas; only `getSession` and the
  `lib/db/*` modules are mocked, so 401/403/404/409 and the success envelope are genuine handler
  behavior.
- Added the 404 unknown-id, past-month 400, and `override: false` 400 cases deferred by E2-07 and
  E2-08. Cron routes are verified bearer-only with a mocked-but-unused HR session; health is the
  unauthenticated exception with a 503 DB-failure envelope.
- CI needed no edit: the `quality` job runs `npm run test`, which discovers `tests/**/*.test.ts`.
  The separate `database` job owns `test:db`, so the two suites never share a worker or database.

## Decisions

- No production code changed. The tests pin the existing envelope and role-gate contract, so a
  future status-code or gate change must update the matrix deliberately.
- `LOG_LEVEL: "silent"` in a mocked `@/lib/config/env` is safe: pino reads it at module load and the
  mock bypasses the env zod enum, so the four suites stay quiet without touching the logger.
- 409s are produced with `new AppError(ERROR_CODES.CONFLICT, message, 409)`; `AppError` has no
  `.conflict()` helper. Route tests construct the same error the DB layer throws.

## Blast-radius notes

`graphify query` after refreshing the graph showed the new test nodes connecting only to the
intended handlers, `lib/auth/policy.ts`, `lib/api/errors.ts`, and `withApiHandler()`;
`graphify affected` returned no dependents for the test files. `graphify-out/` is gitignored and the
hook had not indexed the new files, so `graphify update .` was required before the check was
meaningful.

## Validation issues

- [FIX NOW — fixed] The first matrix version asserted only `routes.toHaveLength(19)` — its own
  hand-maintained array. A new `app/api/**/route.ts` could land with no case and CI would stay
  green. The guard now walks the real `app/api` tree, derives each path and exported verb, and
  fails if any is missing from the table (or if a table entry names no real route).
- [FIX NOW — fixed] E2-07/E2-08 deferred handler-level 404 unknown-id and past-month 400 coverage
  to E2-15. Added audit 404 (`getAuditReport` returns null), policies 400 (past month) and 404
  (unknown employee), decision/override 404 (DB notFound), and override 400 (`override: false`).
- [Fixed — reviewer BACKLOG] The jobs test named "does not grant access from a valid user session
  alone" could not prove a proxy claim because it bypasses `proxy.ts`. Renamed to "never consults a
  user session"; proxy bypass coverage remains in `tests/proxy-auth.test.ts`.
- [Fixed — reviewer BACKLOG] The accrual delegation test only matched a period regex, so a
  hardcoded valid-but-wrong period would pass. It now compares against `accrualPeriod()`.
